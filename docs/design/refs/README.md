# 디자인 레퍼런스

오너가 Mobbin 등에서 고른 화면 스크린샷을 주제별 폴더로 넣는다. 에이전트 팀은 Mobbin에 접근할 수 없어서 이 폴더가 기준이 된다.

- `league/`: 순위표, 경기 상세, 라인업, 선수 카드 (FotMob, OneFootball, 365Scores)
- `match-recording/`: 경기 중 빠른 입력 화면
- `chat/`: 채팅 목록·방 (카카오톡, Discord, Slack)
- `attendance/`: 체크인·스트릭·랭킹 (Strava, Duolingo)
- `auth/`: 소셜 로그인·온보딩 (토스, 당근)

파일 이름은 `<앱>-<화면>.png`. 무엇이 좋은지 한 줄 메모를 같은 이름의 `.md`로 남기면 더 좋다.
