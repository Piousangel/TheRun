# 더런 로고 개편 (2026-11-16)

오너 요청: "토스·카카오·배민 시니어 디자이너를 모셔 놓고 논의 → 디자인 → 리뷰 후 로고 변경, 오늘 저녁 반영".
아래 패널 의견은 실제 인물이 아니라 그 관점으로 진행한 디자인 리뷰다.

## 1. 기존 로고 진단 ([0-before](./logo-2026-11-16/0-before.png))
금색 그라데이션 달리는 사람(획 9개 + 잔상 선 2개).
- **토스 관점**: 16~32px(탭 아이콘·헤더)에서 형태가 뭉개진다. 잔상 선은 작게 쓰면 사라진다.
- **카카오 관점**: 흔한 '달리는 사람' 클립아트라 풋살·클럽 정체성이 없다. 그라데이션은 흰 배경에서 탁하다.
- **배민 관점**: 한 번 보고 기억할 캐릭터가 없다. 단색으로 바꾸면 무너진다.
→ 요구사항: **16px에서 읽힐 것 · 단색으로 성립할 것 · 풋살(공)과 런(속도)을 담을 것**

## 2. 1차 시안 ([1-round1](./logo-2026-11-16/1-round1-ABC.png))
| 안 | 내용 | 평가 |
|---|---|---|
| A | R 모노그램(볼 = 원) | 작아도 읽힘, 이니셜이라 기억에 남음 / 공이라는 게 약함 |
| B | 속도 사선 + 공 | 경쾌함 / 흐린 사선이 흰 배경에서 사라지고, 테크 로고처럼 보임 |
| C | 하프라인 + 센터서클 + 공 | 풋살 이야기는 가장 분명함 / 범용 심볼 같음 |

## 3. 2차 ([2-round2](./logo-2026-11-16/2-round2.png))
C2는 그리스 문자 'Φ'로 읽혀서 탈락했다. A2·A3는 줄기와 볼 사이 틈 때문에 'I R'로 읽혔다. A3의 곡선 다리는 산만했다.

## 4. 최종: F1 ([3-final](./logo-2026-11-16/3-final-F1-F2.png))
- **R = Run**: 줄기와 D형 볼이 한 덩어리다.
- **볼의 오각형 구멍 = 축구공 패널**: 크게 보면 공이 보이고, 16px에서는 단단한 R로 읽힌다.
- **둥근 끝 직선 다리**: 앞으로 내딛는 스트라이드다.
- **색**: 브랜드 금색 `#C8A858` 단색, 그라데이션 없음. 밝은 배경에서는 대비(약 2:1)가 부족해 **검정 타일 안에 금색**(`TheRunBadge`)을 쓰거나 진한 금색 `#8A6D1F`(`tone="brandOnLight"`)를 쓴다.
- 패널 최종 의견
  - 토스: 16px 판독·단색 OK
  - 카카오: 한 글자에 클럽 이야기(런·공)가 담김
  - 배민: 둥근 획이 친근하고 기억하기 쉬움

## 6. 2차 개편 (같은 날 저녁, 오너 피드백)
오너 피드백: "로고 안에 더 축구공처럼 생긴 아이콘", "R 가운데 작대기(다리)가 너무 길다", "TR(더런) 조합도 검토".
- 4라운드([7](./logo-2026-11-16/7-round4-ball-attempt.png)): 오각형에서 솔기 선을 뻗게 그렸더니 해·별처럼 보였다(탈락).
- 공 다시 그리기([8](./logo-2026-11-16/8-ball.png)): 클래식 축구공 = 가운데 오각형 + 가장자리 오각형 패널 5개(원에 정확히 클리핑).
- 5라운드([9](./logo-2026-11-16/9-round5-TR.png)): R3(R의 속 공간에 축구공) / **TR3(T 가로대 + R + 축구공, 다리 단축)** / TR4(가로대가 위 전체를 덮음 — 볼과 붙어 뭉개져 탈락)
- **최종 TR3**: T+R+공으로 '더런'과 풋살이 한 기호에 담겼다. 44px에서 공이 보이고, 16px에서는 TR로 읽힌다. 다리는 볼 폭 안에서 끝나 비율이 안정됐다.
- 결과 이미지 4·5·6은 TR3 기준으로 갱신했다.
