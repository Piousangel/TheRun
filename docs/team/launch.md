# 런칭 체크리스트 (더런 팀의 첫 목표)

오너 결정(2026-11-15): 팀의 첫 목표는 **클럽 런칭**이다. 20명에게 링크를 보내 실제 주간 루프(투표 → 팀 나누기 → 경기 기록 → 공지)를 돌릴 수 있는 상태를 말한다.
- 이 문서는 아침 팀이 매일 갱신한다. 항목이 끝나면 PR 번호를 적고 체크한다.
- 순서를 바꾸려면 근거를 회의록에 쓴다. 출처 문서와 충돌하면 `docs/product-decisions.md`가 이긴다.
