# 팀 방향 (살아있는 문서)

아침 팀이 매일 갱신한다. 틀린 줄은 지우고 정리한다.

## 이번 주 숫자 목표 (11/16–22)
스프린트 완료 행 **2개**(기반, S0). 진행: 1/2 (11/17 기준 기반 완료).

## 현재 방향
1. 첫 목표는 클럽 런칭([launch.md](./launch.md))이다. UI 개편 → 자체 로그인 → Supabase 복귀 → 핵심 기능 순서로 간다.
2. 실사용자가 생기기 전까지는 '이번 주 경기를 이 앱으로 운영할 수 있나'가 판단 기준이다.

## 부족한 점 (확인된 것, 2026-11-15)
- 2026-09-17 이후 두 달간 개발이 멈췄다. UI 개편은 1단계만 끝났다.
- Supabase 프로젝트가 사라진 상태다. 원인 미확인(`docs/supabase-reconnect.md`).
- 실사용자가 없어 피드백 경로가 없다.
